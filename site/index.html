☁️ Cloudledger
GitHub · Live app

Know what Azure costs. And exactly why.

Cloudledger is an open-source Azure cost management app built by Anuj Singh (anuj7052). Daily spend down to the resource, RI vs pay-as-you-go, BOQ vs actual and customer billing — in one place, read with your own Azure permissions.

Open the live app⭐ Star on GitHub

Features

  • Azure cost dashboard — daily and monthly spend, highlighted notes explaining every change
  • Cost Explorer — service → resource group → resource → meter
  • BOQ vs actual — planned vs real Azure cost
  • Azure Billing CRM for CSP partners — customers, subscriptions, invoices, distributors, profit, POs and BOQs
  • Pending bills & approved reminder mails, audit log with who/what/when/why
  • Microsoft Entra sign-in, read-only by default

Tech stack

Python FastAPI · React · Vite · Tailwind CSS · Azure (App Service, PostgreSQL, Blob Storage, Communication Services, OpenAI) · Microsoft Entra ID.
